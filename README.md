## 三个带宽数字，别混着用

常见说法有三组数：上传至少 1.5Mbps、1080P 推流码率 3–6Mbps、手机专线 5M 起电脑 10M 起。它们说的是不同环节的事，混成一个数就会算错预算。

1.5Mbps 是平台侧的最低上传建议，来自卖家导航类网站的整理，意思是低于这个量级视频流本身就推不上去，属于下限。1080P 推流 3–6Mbps 是编码侧的实际占用，部分服务商公开说明里给的就是这个区间，指编码器输出多少数据。手机 5M、电脑 10M 起是采购专线时的工程口径，除了码率还要留出抖动、丢包、其他设备占网和高峰波动的余量。

| 数字 | 说的是什么 | 怎么用 |
| --- | --- | --- |
| 1.5Mbps | 平台侧建议的最低上传速度 | 判断一条线路能不能开播的下限 |
| 3–6Mbps | 1080P 推流实际码率占用 | 估算单场直播吃掉多少带宽 |
| 手机 5M / 电脑 10M 起 | 采购专线时的起步配置 | 下单按这一档选 |
| 1080P 10–20M 以上 | 高帧率、多机位、长时间直播的余量 | 重要场次往上加 |

真正影响观看体验的是上传速度、延迟、丢包率、抖动和线路本身稳不稳，码率只是其中一个变量。测速跑出 100M 但每几分钟抖一次，直播照样卡。正式开播前用真实 TikTok 直播环境跑一场，比对着测速截图判断靠谱。

## 按场景定带宽：四个档位

单台手机、真人出镜、普通带货聊天，5M 起步够用。长时间播或对稳定性要求高，直接上 10M，多出来的部分买的是波动时的缓冲。

单台电脑推 720P，约 4Mbps 以上上传能力可以支撑。单台电脑推 1080P，10M 起步，10–20M 更稳，1080P 60FPS 和画面变化快的场景往 20M 靠。

多台设备同时开播别做除法。三台手机各需要约 5M，不能让它们共享一条 5M 线路，按“在线设备数 × 单设备需求”再留冗余，多直播间团队按 20M、50M 甚至更高规划。

对照上表会发现，WePC 这些套餐标的是 50M 到 200Mbps 带宽，单场 1080P 推流在带宽上不构成瓶颈。买这类 VPS 时真正要比的是回程线路和 IP 类型，带宽反而不是最需要纠结的那一项。

## 卡顿不只是卡，还可能被当成播放录像

TikTok 帮助文档提示，为避免画面卡顿和倒转，务必使用高速网络连接直播。这类问题通常表现为缺乏互动和画面长时间静止，会让直播更容易被判定为播放录像。官方也不建议在直播中播放以前录制的内容，使用无脸特效同样可能因为互动率低被当成录音处理。

这条对预算紧张的团队最有参考价值：省带宽省出来的抖动，代价可能不只是观众流失，还可能是流量判定。稳定性属于内容质量的一部分。

## IP 比带宽更容易出事

原生家宽 IP 由当地 ISP 分配，在 IP 检测工具里显示家庭宽带特征；机房 IP 一眼能看出是数据中心段。双 ISP 指一台服务器同时具备两个 ISP 的认证属性，检测结果更接近真实家庭网络。做美区直播的团队通常优先找双 ISP 家宽 IP 的节点，做东南亚同样如此。

账号配比也容易踩坑。服务商普遍提示同一个 IP 下登录过多账号容易触发风控，导致限流甚至封禁，常见做法是一个 IP 对应一个直播账号。多账号团队要按账号数量配 IP，不是给一条线路无限加带宽就能解决。
